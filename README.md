# JavaScript Strings: Slug Generator

A small JavaScript exercise focused on string processing and reusable functions.

## What it does

The `slugify(title)` function converts a title to lowercase and replaces spaces with hyphens, producing a URL-friendly slug.

Example: `"Arrays for beginners"` becomes `"arrays-for-beginners"`.

## Concepts practiced

- String methods: `toLowerCase()`, `split()`, and `join()`
- Function declarations and return values
- Transforming input data
- Testing a function with different strings

## Run locally

Open `index.html` in a browser and view the function results in the developer console.

## Project context

An introductory GoIT JavaScript assignment about string manipulation.
